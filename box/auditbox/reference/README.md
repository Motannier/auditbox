# 交换机手册速查数据

此目录存放产品运行所需的只读手册数据，与推荐图、命令补全和模型配置分别维护。语法模板仅供查阅，不能直接下发执行。

指令速查界面使用 `web/src/lib/guide/networkDeviceScenarios.js` 中按用途整理的常用操作卡片。此目录保留完整整理结果，供后续风险规则等功能使用；界面不展示全量目录，也不请求其接口。

数据来自已整理的 `命令提取/review_v3/risk_export` 中的华为、思科、中兴 JSON，沿用源文件的命令分类和风险标记。更新命令：

```sh
node tools/build_switch_reference.mjs /path/to/review_v3/risk_export
```

`data/manifest.json` 记录品牌、分类策略版本、命令名称数、语法形式数和输入/输出 SHA-256。`.json.gz` 是确定性生成的压缩 JSON，schema 1：`strings` 为共享字符串表，`entries` 为 `[原始变体ID, 命令名索引, 语法索引, 风险0/1, 原因索引, 型号版本索引, 视图及限制索引, 来源索引]`。数据保留备注中的完整型号/版本/视图绑定、型号限制和 M 编号来源，包含 Excel 单元格摘要之外的追溯信息。

同名命令归组展示，各参数形式及风险结论分别保留。分类策略将配置、文件或运行状态变更（包括主动探测、调试、清计数等）标为有风险，将查询、帮助、纯视图切换等标为无风险；无法确认的按有风险处理。标为无风险的命令仍可能泄露信息。覆盖范围限于已整理且成功解析的文档，具体命令是否适用须核对设备型号和固件版本。

API 按品牌加载数据，按命令名称归组并分页返回，供调用方按需读取，无需加载全部文档或启动模型。
