# 交换机手册速查数据

此目录保存从交换机手册整理的只读命令资料，包括语法形式、风险标记、型号版本和来源。它供后端按需查询，与前端常用操作卡片、推荐图和执行规则分别维护。语法模板用于查阅，不能直接下发执行。

## 工作台怎样使用这些资料

当前指令速查界面使用 [networkDeviceScenarios.js](../../../web/src/lib/guide/networkDeviceScenarios.js) 中按用途整理的常用操作卡片，不展示此目录的全量资料。后端的 `/api/commands/reference` 接口保留按平台、命令名称和风险标记查询的能力，按命令名称归组并分页返回；查询无需启动模型。

同名命令的各参数形式与风险结论分别保留。分类策略将配置、文件或运行状态变更标为有风险，包括主动探测、调试和清计数；查询、帮助与纯视图切换标为无风险，无法确认时按有风险处理。

“无风险”标记仅反映资料分类，查询命令仍可能暴露敏感信息。覆盖范围限于已整理并成功解析的文档，具体语法需核对设备型号、系统版本与当前视图。执行前检查使用独立的 [风险规则数据](../security/data/README.md)。

## 更新数据

日常构建直接使用已有运行数据。需要重新生成时，准备符合构建脚本格式的外部整理结果目录，其中包含 `华为.json`、`思科.json` 和 `中兴.json`，再从仓库根目录运行：

```bash
node tools/build_switch_reference.mjs /path/to/risk_export
```

脚本打包已有分类结果，不直接解析 PDF 或重新分类命令。输出覆盖本目录的 `data/`；源资料版本与分发权限记录见 [第三方说明](../../../THIRD_PARTY_NOTICES.md)。

## 文件格式与追溯

[data/manifest.json](data/manifest.json) 记录品牌、分类策略版本、命令名称数、语法形式数和输入／输出 SHA-256。`.json.gz` 为确定性生成的压缩 JSON，使用 schema 1；`strings` 是共享字符串表，`entries` 每条记录为：

```text
[原始变体ID, 命令名索引, 语法索引, 风险0/1, 原因索引, 型号版本索引, 视图及限制索引, 来源索引]
```

数据保留整理结果中型号、版本、视图的绑定关系、型号限制与 M 编号来源，便于回查原始资料。加载与查询实现见 [catalog.py](catalog.py)。
