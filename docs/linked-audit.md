# 轻量关联日志

`audit_logins`、`audit_executions`、`audit_inputs`、`audit_behaviors` 保存在业务 SQLite 数据库中。
`audit_changes` 记录同一事务提交的递增变更，管理端按游标读取新增和更新。
`box_info` 保存稳定的 `box_id` 和 `last_system_update_at`。读取到有效 CPU 序列号时，`box_id` 按原文保存为小写十六进制，
优先读取 `/proc/cpuinfo` 的 `Serial`，其次读取内核 SoC 设备的 `serial_number`。
设备树提供的板卡序列号不作为 CPU 身份来源。

读取不到有效序列号时保留已有 ID，首次初始化时才生成兼容 ID。
升级将旧生成 ID 保存在 `box_identity_aliases`，通过 `legacy_box_ids` 返回，
管理端据此沿用原档案、历史关联和同步游标。迁移更新记录中的设备标识并追加同步修订，
保留原始变更日志；导出旧修订时映射到新标识。
在新硬件上部署时应独立初始化数据库。已保存的 CPU 序列号与当前硬件不符时，初始化会被拒绝。

签名凭证携带成功登录记录的 ID，刷新或校时换发凭证时保留该关联。
旧凭证或旧连接缺少登录记录时，关联字段留空。登录记录未设置登出或登录结束时间字段。
人工／速查来源展示为手动输入；Agent 的已验证账号、聊天 ID、运行轮次、问题与目的通过
与命令相同的有序输入帧传递。浏览器不能注入审计上下文或冒充 Agent 输入。
审批与二次确认分别记录为行为；终端断开记录连接状态，不推断退出登录或执行成功。

命令输出先合并，再在静默时写入脱敏摘要，最多保留末尾 16000 字符。转发给终端的数据保持原样。
缺少退出码时，通过提示符推断的命令结果标为未知。代理启动时恢复未完成执行的状态。
规则与模型审查沿各自链路运行，审计负责记录安全决策。
脱敏覆盖敏感字段和常见命令凭据语法，无标识秘密仍可能出现在设备输出中。
JSONL 保留兼容记录，历史文件保持原样。新记录不保存普通按键原文和原始终端输出字节。

## 历史格式转换

`python -m auditbox.audit.legacy --directory /var/log/auditbox` 默认只预览；
确认设备身份、关闭活动终端并备份 SQLite 与原 JSONL 后，添加 `--apply` 执行转换。
使用当前实例的 `PYTHONPATH` 与 `AUDITBOX_DB_PATH`，由具有数据库读写权限的服务账号执行。

- 一条实际命令对应一条执行与一条输入详情；确认请求、批准和实际下发更新同一条记录。
  重复执行的同名命令分别记录，速查填入与原始按键不计为命令执行。
- 终端会话建立／结束、速查操作、确认及旁路审查归入行为。
  旧数据只按已有登录事实和聊天标识关联，缺失时留空。
- 来源明确时保留，未记录时为 `unknown`；结果未记录或仅靠提示符推断时仍为未知。
- 输出按旧事件顺序归入命令，统一脱敏并限制摘要长度；摘要可能包含命令回显或异步输出。
  连接横幅、按键和完整输出可在历史原文中核对。
- ID 由设备、会话和记录位置派生，`audit_legacy_imports` 保存来源文件 SHA-256 和转换版本。
  转换后的记录、变更日志与检查点在同一事务提交；重复转换不重复插入，已转换原文发生变化则报错。
  已有新版记录的会话会跳过，避免重复转换。
