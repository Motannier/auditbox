# 共享终端工具设计

Gateway 持有浏览器正在使用的终端连接，Agent 通过仅允许本机访问的内部接口复用该连接。人工输入与助手命令作用于同一设备、同一 CLI 状态，便于连续操作和关联审计。Agent 无需保存设备密码或另建 SSH/Telnet 连接。

| 工具 | 作用 | 审批 |
| --- | --- | --- |
| `list_terminal_sessions` | 查看可用终端 | 无需逐次审批 |
| `read_terminal` | 读取指定终端的有限历史 | 无需逐次审批 |
| `send_terminal_command` | 向指定终端写入命令 | 每次审批 |
| `interrupt_terminal` | 向指定终端发送 Ctrl+C | 每次审批 |

执行总开关关闭时，终端执行和继续待审批运行均被拒绝。开启后，命令写入和 Ctrl+C 进入 Agno 暂停/审批流程。工具名称与参数须与已保存的待审批记录一致，校验通过后才接受用户的批准或拒绝决定。

Gateway 检查 Agent 执行开关、终端会话和连接状态，再将输入写入原 Gateway→Proxy 连接。工具审批通过后，命令继续经过确定性命令闸门：需确认的命令另行确认，硬阻断命令拒绝下发。人工介入时，正在等待的工具可返回 `interrupted_by_user`，后续步骤应以实际工具状态为准。

工具返回限定长度的输出和执行状态，操作员、会话及运行信息随操作写入审计。命令已下发与成功完成分别判断；缺少可靠退出状态时，结果保留为未知。完整时序见 [系统架构](../../docs/ARCHITECTURE.md)，记录方式见 [关联审计](../../docs/linked-audit.md)。
