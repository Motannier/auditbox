# 服务器版终端工具

Gateway 持有浏览器正在使用的终端连接，Agent 通过仅允许本机访问的内部接口复用该连接。工具包括 `list_terminal_sessions`、`read_terminal`、`send_terminal_command` 和 `interrupt_terminal`。

执行总开关关闭时，终端执行和继续待审批运行均被拒绝。开启后，命令写入和 Ctrl+C 进入 Agno 暂停/审批流程。工具名称与参数须与已保存的待审批记录一致，校验通过后才接受用户的批准或拒绝决定。

Gateway 检查 Agent 执行开关、终端会话和连接状态，再将输入写入原 Gateway→Proxy 连接。工具审批通过后，命令仍需经过确定性风险闸门，命中危险规则时须二次确认。人工介入可能中断正在等待的 Agent 操作，后续步骤应以实际工具状态为准。

工具返回限定长度的输出和执行状态，操作员、会话及运行信息随操作写入审计。终端读取与有副作用的写入分别采用对应的审批策略。完整时序见 [服务器架构](../../docs/ARCHITECTURE.md)。
